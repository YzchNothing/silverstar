# SilverStar / 纯银星

Minecraft **1.20.1 · Forge** 的拔刀剑（SlashBlade: Resharped）附属 mod。

新增一把刀「纯银星」，一个刀技「天堂陨落」，两个刀的特殊效果「唯余其一」「星蚀」。
刀身、刀光、幻影剑、次元斩风纹、斩击波全部换成流动的星空渲染。

- 作者：GoldenStar
- 版本：1.0.0
- 许可证：MIT（美术资源与第三方内容的归属见文末「授权与致谢」）
- 前置：SlashBlade: Resharped `1.1.23` ~ `1.1.x`、SlashBlade Addon (SJAP) `1.1.10` ~ `1.1.x`

## 内容

| 项目 | 说明 |
|---|---|
| 刀 | **纯银星** — 基础伤害 75，耐久 75，自带 力量 20 / 耐久 3 / 锋利 10，挂在腰间（katana 挂法） |
| 刀技 SA | **天堂陨落** — 起手沿用拔刀剑的第一刀动作，随后半径 **9 格**内全体落下一轮次元斩；范围内没有目标时不空放 |
| 特殊效果 SE 1 | **唯余其一** — 周围每个敌人让第二段伤害 +15%（最多 +90%）；每击杀一次攒一层「裁定」，每层再 +2%；攒到 20 层进入「终局」10 秒必暴 |
| 特殊效果 SE 2 | **星蚀** — 命中给目标叠「星痕」（最多 5 层，每层让你多打它的 **+4%**）；第 5 层引爆，造成 `max(目标血上限 15%, 你的面板攻击力)`；带星痕的目标死亡时按层数爆炸并传染给周围 |
| 星空渲染 | 刀身（可关）/ 刀光 / 幻影剑 / 次元斩风纹 / 斩击波，均使用自写着色器，观感对齐原版「寰宇支配之剑」 |
| 配置 | `config/silverstar-client.toml` 里 `bladeStarRender`（默认 `false`）：是否让**刀身**也铺星空；刀光等光效不受它影响 |

### 关于渲染与光影

- 开光影（Oculus / Iris）时，星空层会自动让位给原版材质，只保留配色（青 / 深蓝 / 紫）。
  这是刻意的：Iris 接管核心着色器后我们的程序不会被调用，硬画也画不出来。
- 刀身那一路用的是普通半透明混合，不加光影时才是「整块星域」的观感。

## 合成

工作台 3×3：

```
白狐(2000 杀)  下界合金锭   黑狐(2000 杀)
消失诅咒附魔书   铁剑        绑定诅咒附魔书
下界合金锭      死念(0 杀)   下界合金锭
```

- 「白狐」「黑狐」= `slashblade:fox_white` / `slashblade:fox_black`，击杀数需 **2000**
- 「死念」= `slashblade_addon:nihilbx`，无击杀数要求
- 两本附魔书分别是**消失诅咒**与**绑定诅咒**
- 结果：一把新的 `slashblade:slashblade`，即纯银星

> 用指令或白板拔刀剑强行凑出来的刀不会自动带上这些数据，请按配方合成。

## 构建

```sh
gradlew.bat build          # Windows
./gradlew build            # Linux / macOS
```

产物：`build/libs/silverstar-1.0.0.jar`，丢进 `mods/` 即可。
