## 正文

### 简介

**纯银星**是《拔刀剑：重锋》的附属模组，新增同名太刀「纯银星」，以及一个刀技「天堂陨落」、两个特殊效果「唯余其一」与「星蚀」。

它的主要特征是**星空渲染**：刀身、刀光、幻影剑、次元斩的风纹、斩击波都换成了流动的星域，观感对齐原版「寰宇支配之剑」。星点按 16×16 的点阵字形铺开并缓慢漂移，不是一张静态贴图。

### 刀：纯银星

| 属性 | 数值 |
|---|---|
| 基础伤害 | 75 |
| 耐久 | 75 |
| 自带附魔 | 力量 20、耐久 3、锋利 10 |
| 挂法 | 腰间（katana） |
| 刀技 | 天堂陨落 |
| 特殊效果 | 唯余其一、星蚀 |

### 刀技：天堂陨落

起手沿用拔刀剑的第一刀动作，随后半径 **9 格**内全体落下一轮次元斩。范围内没有目标时不会释放。

### 特殊效果：唯余其一

- 周围每有一个敌人，第二段伤害 +15%，最多 +90%
- 每击杀一次攒一层「裁定」，每层 +2%
- 20 层进入「终局」，10 秒内必暴

### 特殊效果：星蚀

- 命中叠「星痕」，最多 5 层，每层对其 +4%
- 第 5 层引爆：`max(目标血上限 15%, 面板攻击力)`
- 带星痕的目标死亡会爆炸并按层数传染

### 合成

```
白狐(2000 杀)   下界合金锭   黑狐(2000 杀)
消失诅咒附魔书    铁剑      绑定诅咒附魔书
下界合金锭      死念(0 杀)  下界合金锭
```

### 前置与版本

| 需要 | 版本 |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47.x |
| 拔刀剑：重锋 | 1.1.23 ~ 1.1.x |
| SJAP | 1.1.10 ~ 1.1.x |

拔刀剑版本范围是锁死的：星空渲染依赖 mixin 对准 1.1.23 的方法签名，版本不符会启动失败。

### 配置文件

`config/silverstar-client.toml`

| 键 | 默认 | 说明 |
|---|---|---|
| `bladeStarRender` | `false` | 是否让刀身（含刀柄、刀鞘）也铺星空。刀光等光效不受影响 |

### 已知限制

- 开光影（Oculus / Iris）时星空层会让位给原版材质，只保留配色，关光影即恢复
- 用指令拼出来的刀不带刀技与特殊效果，需按配方合成
- SJAP 是硬前置（配方里的「死念」出自它），没装会无法启动
