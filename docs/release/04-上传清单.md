# 上传清单

## 一、上传前必做的三件事

1. **图标**：你进游戏截图后放到 `docs\release\screenshot.png`，然后跑一次
   `python _材质\发布\make_icon_from_shot.py`，会生成
   `src\main\resources\icon.png`（400×400，打进 jar 里当模组图标）与 `docs\release\icon_from_shot_512.png`。
   生成后再跑一次构建，jar 里才会带图标。
2. **仓库地址**：CurseForge / MC百科 都要填源码或反馈链接。仓库建好后把地址填进
   `01-curseforge-描述.md`、`02-mcmod-简介.md`、`gradle.properties`（可选）。
3. **构建正式包**：`gradlew.bat build`，产物 `build\libs\silverstar-1.0.0.jar`。
