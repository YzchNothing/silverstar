## SilverStar / 纯银星 1.1.0

新增第二把刀「金色星」，以及左臂星空、四套金色着色器。

### 新增

- **刀：金色星** — 伤害 70、耐久 70，自带力量 20 / 耐久 3 / 锋利 10 / 火焰附加 5，自带合成配方
- **刀技：余烬** — 蓄力后甩出三道金色刀光，三段龙息伤害并点燃 4 秒
- **特殊效果：余温**（需 1 级）— 命中留印记 6 秒，再打追加 35% 攻击力；击杀带印记目标回复 30% 最大生命并传染印记
- **特殊效果：碎金**（需 30 级）— 星屑三连（合计 60% 面板）+ 按目标残血比例追加残光（10%~90%）
- **左臂星空壳** — `armRenderMode` / `armColorMode` 可配置，主手拿哪把刀就用那把的颜色

### 变化

- 金色星空走独立着色器（刀身、刀光、风纹、左臂、次元斩球各自配色），不与纯银星共用
- 次元斩的球与风纹改为按刀取色：纯银星青、金色星金
