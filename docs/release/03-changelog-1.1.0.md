# 1.1.0

Minecraft 1.20.1 / Forge 47。

## 新增

- **刀：金色星**（伤害 70、耐久 70，力量 20 / 耐久 3 / 锋利 10 / 火焰附加 5）+ 合成配方
- **刀技：余烬** — 三道金色刀光，三段龙息伤害并点燃 4 秒
- **特殊效果：余温**（1 级）— 命中留印记 6 秒，再打追加 35% 攻击力；击杀回 30% 生命并传染印记
- **特殊效果：碎金**（30 级）— 星屑三连（合计 60% 面板）+ 按目标残血比例追加残光（10%~90%）
- **左臂星空壳** — 配配置项 `armRenderMode` / `armColorMode`，金色星与纯银星各自用本色

## 变化

- 金色星空：独立的 `cosmic_gold` 系列着色器（刀身、刀光、风纹、左臂、次元斩球各有配色）
- 次元斩的球与风纹按刀取色：纯银星青、金色星金
- `armRenderMode` 不为 0 时，主手拿哪把刀，左臂就用那把刀的颜色

## 兼容

Minecraft 1.20.1 / Forge 47.x / SlashBlade: Resharped 1.1.23+ / SJAP 1.1.10+
