# 1.0.0 — 首个正式版

Minecraft 1.20.1 / Forge 47。

## 内容

**刀：纯银星**

- 基础伤害 75、耐久 75，自带力量 20 / 耐久 3 / 锋利 10，腰间挂刀
- 刀技「天堂陨落」：蓄力后释放，对半径 9 格内目标释放次元斩，随后瞬移到血量最低目标上方（或后方），释放空坠斩（或虚无刀界）
- 特殊效果「唯余其一」：周围每多一个敌人第二段伤害 +15%（封顶 +90%），击杀攒「裁定」每层 +2%，20 层进入 10 秒必暴
- 特殊效果「星蚀」：命中叠星痕（最多 5 层，每层 +4%），第 5 层引爆 `max(目标血上限 15%, 面板攻击力)`，带痕目标死亡时爆炸并传染

**星空渲染**

- 刀身、刀光、幻影剑、次元斩风纹、斩击波共用一套流动星空，星点按 16×16 点阵字形铺开
- 刀柄、刀鞘是否铺星空可配置（`bladeStarRender`，默认关，改完立刻生效）
- 刀光四层共用同一片星空，不再重影
- 光影下自动回退原版材质
