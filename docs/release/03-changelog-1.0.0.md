# 1.0.0 — 首个正式版

首个公开发布版本。1.20.1 / Forge 47。

## 内容

**一把刀：纯银星**

- 基础伤害 75、耐久 75，自带力量 20 / 耐久 3 / 锋利 10，腰间挂刀
- 刀技「天堂陨落」：起手沿用第一刀动作，随后 9 格半径内全体落下次元斩，无目标不空放
- 特殊效果「唯余其一」：被围越多伤害越高（每个 +15%，封顶 +90%），击杀攒「裁定」层数，20 层进入 10 秒必暴
- 特殊效果「星蚀」：命中叠星痕（最多 5 层，每层 +4%），第 5 层引爆 `max(目标血上限 15%, 面板攻击力)`，带痕目标死亡时爆炸并传染

**星空渲染**

- 刀身、刀光、幻影剑、次元斩风纹、斩击波均为流动星空，星点按 16×16 点阵字形铺开并漂移
- 刀身是否铺星空可配置（`config/silverstar-client.toml` 的 `bladeStarRender`，默认关）
- 刀光改为**单层共用一片星空**：原版一道刀光画四层，四层采样同一片空间方向，不再重影
- 开光影时自动回退原版材质并保留配色

## 已知问题

- 用指令拼装出来的刀不会带刀技与特殊效果
- 光影下星空不可见（由着色器管线决定，非本模组可控）
- 刀刃那一小片 UV 只有 39×196 像素去铺 16×278 单位的刀身，贴图纵向必然被拉伸约 3.4 倍
